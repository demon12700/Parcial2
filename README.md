# Parcial2

Aplicación web desarrollada en **React** y **TypeScript** para la gestión, búsqueda y filtrado de un catálogo de naves espaciales.

## Temática y Descripción

**Temática:** Flota espacial y naves de exploración.

El proyecto permite visualizar un listado de naves espaciales con sus especificaciones técnicas (código identificador, categoría, estado operacional, capacidad de tripulación y rango en años luz). Incluye las siguientes funcionalidades:
* **Búsqueda en tiempo real:** Filtrado por nombre o código IDN de la nave.
* **Filtro por categoría:** Selección entre *Crucero*, *Scout*, *Estación* o *Carga*.
* **Gestión de favoritos:** Posibilidad de marcar/desmarcar naves favoritas y activar una vista exclusiva para ellas.

## Tecnologías Utilizadas

* React
* TypeScript
* Vite
* CSS

## Instrucciones para correr el proyecto localmente

1. **Clonar el repositorio o descargar el código fuente:**

al descargar y abrir el proyecto en vscode o otro compilador de codigo, utilizar **npm install** para descargar todas las dependencias necesarias del proyecto. al tener las dependencias descargadas, utilizar **npm run dev** para inicializar el proyecto, en la consola te aparecera el url de donde tienes que ir para poder ver la pagina del proyecto, donde podras utilizar las funciones del programa. Puedes copiar el url o directamente clickearlo.
